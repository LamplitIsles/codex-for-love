# 0.1.0 release record

`@jaminzhou/codex-app-server-client@0.1.0` was published to the public npm registry on
**2026-09-09 at 13:32:27 UTC**, with `latest` pointing to `0.1.0` at verification.
This is the first non-preview release of this unofficial client, still a pre-1.0 API.

## Install

```bash
npm install --save-exact --ignore-scripts --include=optional @jaminzhou/codex-app-server-client@0.1.0
node node_modules/@jaminzhou/codex-app-server-client/examples/stream.mjs
```

The example uses a real pinned app-server with a local mock model provider, without account
credentials or model usage. See the [npm package](https://www.npmjs.com/package/@jaminzhou/codex-app-server-client/v/0.1.0).

## Scope and changes

- Node.js ESM client for local managed-stdio conversations, streaming, explicit approval handlers,
  interruption and persisted-thread recovery. Node.js 18+ can run the installed package; prefer
  a maintained Node.js release. Source builds require Node.js 22+.
- Runtime pinned to `@openai/codex@0.153.4`; client and runtime versions are independent.
- All 158 generated methods have typed raw calls. Runtime validation covers every generated
  request/notification/server request and 155 response methods; three deprecated response
  schemas are not exported upstream.
- Deterministic regressions cover interleaved threads, approval inheritance, interruption and
  managed-process failure/recovery. The Vitest development dependency floor is `4.1.11`.
- No public API, generated protocol or runtime dependency change from `0.1.0-preview.0`;
  default initialization client-info version is now `0.1.0`.

This is not a browser SDK, complete UI, or private Codex Desktop implementation. TCP WebSocket
remains experimental; automatic reconnect/replay is not promised. Consult the
[release-source compatibility contract](https://github.com/JaminZhou/codex-app-server-client/blob/0b0e129230fdc4dd6abd02462cb0ff100c64f76c/COMPATIBILITY.md).
